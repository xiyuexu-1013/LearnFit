# Security and privacy reporting

Please report security or privacy concerns through GitHub's private vulnerability reporting feature if enabled, or contact the maintainer through the verified contact channel on the personal website. Include a concise description, affected version, and a synthetic example when available.

Avoid posting sensitive recordings, participant data, credentials, or detailed reports in public issues. Coordinate handling privately with the maintainer. The project's support scope and response schedule will be specified when the release is approved.
